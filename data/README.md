# NASA POWER provenance

Daily API v2.10.0, accessed 5 October 2026, 2014–2024 in local standard time. Three query points: Meknes (33.89,-5.55), Marrakech (31.63,-8.00), Agadir (30.42,-9.60). These identify gridded products, not farm plots or local weather stations. Original source header lists SYN1DEG, MERRA2 and POWER. Meteorology is modeled/assimilated; radiation combines satellite-derived information. [NASA source and units](https://power.larc.nasa.gov/docs/faqs/data/), [API guidance and spatial resolution](https://power.larc.nasa.gov/docs/tutorials/service-data-request/api/).

The data were obtained from NASA Langley Research Center's POWER project, funded through NASA's Earth Science Division, Daily API v2.10.0 on 2026/10/05. [Attribution guidance](https://power.larc.nasa.gov/docs/referencing/). [POWER's open-data registry](https://registry.opendata.aws/nasa-power/) states unrestricted use/access/download with attribution requested. Code MIT applies separately; source data are not relicensed as repository code.

Manifest contains exact URLs, original downloaded byte SHA-256, geometry/elevation, units and a scientific-content SHA-256. The latter canonicalizes all response fields except volatile server response timings ('times'); re-downloads can have different byte hashes but must reproduce data and scientific metadata. Source revisions fail explicitly. Radiation units are MJ/m²/day for the selected AG community, precipitation mm/day, pressure kPa, temperature °C, wind at 2 m in m/s and RH percent. Raw files are saved locally and ignored in Git. Derived tables must retain NASA attribution.
