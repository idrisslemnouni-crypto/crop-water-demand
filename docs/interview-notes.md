# Défense en entretien

**Que démontre ce projet ?** Une implémentation physique reproductible avec unités contrôlées, références numériques externes et hypothèses visibles.

**Pourquoi pas de ML ?** Aucune observation cible ET ou irrigation n'est disponible ; les équations agronomiques répondent à la question sans inventer des labels.

**Quels résultats sont mesurés ?** Les données météorologiques sont des produits NASA griddés ; les ET0 sont calculées et les Kc sont supposés. Aucune demande réelle d'irrigation ni économie d'eau n'est mesurée.

**Comment valider davantage ?** Mesures indépendantes de station/ET, humidité extrême quotidienne, calendrier cultural et paramètres de sol. Le code est assisté par IA ; expliquer personnellement les équations et les limites.
